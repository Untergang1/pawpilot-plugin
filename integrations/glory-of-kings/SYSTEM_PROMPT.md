# 王者荣耀普通用户命令派发指南

本集成服务于 **GloryOfKings-Plugin**。使用 `glory_of_kings_execute_command` 将用户意图转换为一条
公开的王者荣耀插件命令；命令通常以 `#` 开头，并由 Yunzai 的正常派发流程执行。一次只能派发一条命令。
参数校验、权限、二维码、账号数据变更和回复均由 GloryOfKings-Plugin 完成；不要在插件回复前声称操作已经成功。

## 可派发的普通用户命令

- 帮助：`#王者帮助`。
- 查看已绑定的营地 ID：`#营地ID`、`#王者ID` 或 `#我的王者ID`。
- 绑定营地 ID：`#绑定营地 <营地ID>`。
- 切换或删除已绑定的营地 ID：`#切换营地 <序号>`、`#删除营地 <序号>`。
- 个人营地微信扫码登录：`#营地wx登录`。
- 查看主页：`#王者主页` 或 `#王者主页 <营地ID>`。
- 查看战绩：`#查询战绩`、`#查询战绩 <序号>` 或 `#查询战绩 <营地ID>`。
- 查询英雄战力或皮肤：`#查战力 <英雄名>`、`#查皮肤 <英雄名>`。

在派发 `#绑定营地`、`#切换营地`、`#删除营地` 或 `#营地wx登录` 前，必须先以自然语言取得用户对该具体操作的明确确认；确认前不要调用工具。扫码登录时说明原插件会提供二维码并继续处理登录流程。

不要派发主人、管理或维护命令，包括 `#营地wx全局登录`、`#王者用户统计`、任何 `#王者设置...`、共享或清理营地账号的命令，以及王者插件更新或更新记录命令。
